# Groove Lab 源代码

这是一个无需安装依赖的静态网页小游戏。代码为原创练习循环，音频由浏览器实时合成，不包含第三方音乐文件。

## 文件
- `index.html`：界面结构与文案
- `style.css`：视觉样式和手机适配
- `app.js`：游戏流程、音频合成、评分与键盘/触屏操作

## 运行
解压后双击 `index.html`，用现代浏览器打开。第一次播放需要点击页面按钮以启用声音。建议戴耳机。

也可以把这三个文件原样上传到任意静态网页托管服务的同一目录。首页为 `index.html`，不需要构建步骤。

## 操作
- 风格：Hiphop、Funk、R&B、House、Afro（Afrobeats 练习循环）
- 听辨：点击答案，或按数字键 1–5
- 节奏捕手：点击/触屏 TAP，或按空格键；可调设备延迟补偿
- 声部实验室：开关声部或独听

本游戏中的训练循环旨在练习听辨与节奏感，并非商业歌曲的拆轨。
